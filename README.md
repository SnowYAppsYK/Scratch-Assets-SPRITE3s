# 🚀 Advanced Scratch Sprites (No Blocks)

مجموعة سبرايتات متقدمة ومصممة بالكامل داخل محرر سكراتش، جاهزة للتصدير والاستخدام، وخالية تماماً من البلوكات البرمجية لتمنحك حرية البناء من الصفر.

## 📥 طريقة الاستخدام (How to Use)
1. قم بتحميل ملف الـ `.sprite3` الخاص بالسبرايت الذي تريده من هذا المستودع.
2. افتح مشروعك في سكراتش (Scratch).
3. اضغط على زر "رفع سبرايت" (Upload Sprite) واجلب الملف المفرغ مباشرة.
